# 常见问题

## 为什么启动后显示演示模式？

演示模式便于先体验交互，不需要账号，也不消耗额度。真实巡检需要在设置中切换为「本机 Codex」，完成本机登录后再开始。

## 它会直接调用 ChatGPT 桌面窗口吗？

当前版本接入本机 Codex App Server，通过独立进程复用登录和配置。它不模拟点击桌面聊天窗口，也不读取窗口中已有的对话。详见 [Codex 接入说明](codex-integration.md)。

## 提示找不到 Codex 怎么办？

确认已安装 Codex CLI，或本机有可用的 Codex 桌面安装。在设置里手动填写 `codex.exe` 的完整路径，再运行 `npm run check:codex` 检查。

使用手动路径时应填写实际可执行文件，不要填写目录、终端快捷方式或登录凭据文件。

## 已经登录桌面客户端，为什么还提示需要登录？

海克斯启动的是独立 Codex 进程。它只能使用该进程所在环境可访问的登录状态；桌面窗口可用，并不能证明外部进程也能读取相同登录。可在相同用户环境运行 `codex login` 后重试。

## 模型填什么？

留空使用本机 Codex 配置。需要手动指定时，填写当前账号能够使用的模型名。模型不可用会在真实分析时返回错误。

## 为什么没有读取 PDF、Word、Excel？

当前只实现文本及代码读取，没有 Office、PDF 或 OCR 解析。添加这些文件不会触发有效内容分析，具体支持格式见 [使用指南](usage.md)。

## 新文件为什么没有马上出牌？

文件需要先完成写入、通过扫描过滤并进入队列。真实模式还需要 Codex 确认存在有依据的新任务或问题，并生成三个完整方案。没有发现问题时，不会为了出牌而编造问题。

如果已有卡牌，新发现会进入待看列表，当前卡牌保留。可通过活动记录查看是否收到了文件变化事件。

## 选择方案后，为什么文件没有变化？

默认是只读报告模式。需要修改时，先停止巡检，再开启「选牌后允许修改文件」。即使开启，实际能否修改仍取决于本机 Codex 权限和执行结果，请以报告为准。

## 关闭悬浮窗和收起有什么区别？

横线按钮只收起悬浮窗，后台继续监听。关闭按钮会退出整个应用并停止任务。

## 额度显示不可用，是不是没有额度了？

不是。不可用表示没有获得可读的额度数据。只有明确读到耗尽状态或收到相关错误时，才会按额度耗尽停止。

## 解压后为什么不能只复制 exe？

发布压缩包内包含 Electron 运行时和应用资源。请完整解压并保留同目录文件，再运行 `Hextech Agent.exe`。

## 打包版需要安装 Node.js 吗？

完整解压的 Windows 运行包自带 Electron，运行演示无需另外安装 Node.js。真实模式仍需要可用且已登录的本机 Codex。源码开发和构建才需要 Node.js/npm。

## 报告和设置在哪里？

保存在 Electron 应用数据目录内。设置为 `settings.json`，报告在 `reports` 子目录中。界面可直接打开当前报告。退出后不会恢复内存中的任务队列、待看发现或活动记录。

## 能离线使用吗？

演示模式不调用模型，可以离线体验。真实模式需要 Codex 连接模型服务；工具网络访问关闭，不代表模型服务在本地运行。
