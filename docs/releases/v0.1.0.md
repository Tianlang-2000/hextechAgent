# 海克斯 Agent v0.1.0 · 桌面 Demo

这是首个 Windows x64 预发布版本，用于体验「持续发现问题 → 三张方案牌 → 选牌处理 → 两张后续牌 → 继续巡检」的完整流程。

## 下载与启动

1. 下载附件 `Hextech-Agent-0.1.0-windows-x64.zip`。
2. 完整解压到一个文件夹。
3. 运行 `Hextech Agent.exe`，点击「开始巡检」。

演示模式不需要账号、不调用真实模型，也不消耗额度。运行包自带 Electron，无需另外安装 Node.js。

使用真实分析时，在设置中切换到「本机 Codex」，并确保已安装且通过 ChatGPT 账号登录 Codex。真实调用会使用账号的 Codex 额度。

## 本版功能

- 监听桌面或指定目录，优先检查新文件、新文件夹和内容变化。
- 三个完整方案生成后，再显示桌面悬浮卡牌。
- 选牌后生成报告，并提供继续深入与继续巡检两个后续选择。
- 默认只读；手动开启后，用户选牌才会触发可写处理。
- 手动停止、关闭、额度耗尽或超时后停止任务。
- 提供完整中文使用、接入、架构和开发文档。

## 使用范围

当前支持文本与常见代码格式，不解析 Office、PDF 或图片。默认报告模式不会修改源文件。当前版本未做 Windows 代码签名，暂不包含自动更新。

附件中的 `SHA256SUMS.txt` 提供运行包校验值。PowerShell 校验命令：

```powershell
Get-FileHash -LiteralPath .\Hextech-Agent-0.1.0-windows-x64.zip -Algorithm SHA256
```
