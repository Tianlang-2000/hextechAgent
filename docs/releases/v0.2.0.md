# 海克斯 Agent v0.2.0 · 安装版

本版将解压运行的 Demo 改成常规 Windows 桌面安装体验。

## 下载安装

1. 下载附件 `Hextech-Agent-Setup-0.2.0-x64.exe`。
2. 双击运行，按中文安装向导完成安装。
3. 以后双击桌面的「海克斯 Agent」图标即可打开。

安装程序默认创建桌面和开始菜单入口，可选择安装位置，也可以从 Windows 设置中卸载。运行时不需要 Node.js、npm 或启动脚本。

## 第一次使用

- **先体验一下**：欢迎页一键进入演示，不登录、不消耗模型额度。
- **真实分析**：点击「连接我的 ChatGPT」，再点击「登录 ChatGPT」，到浏览器授权后回到软件开始。
- 安装包已内置官方 Codex 0.164.0 连接组件，无需额外安装 CLI。已有可复用登录时会直接显示就绪。
- 路径、模型等设置移入高级选项，普通用户通常无需填写。

默认只读，选牌后生成报告；需要实际修改文件时，仍由用户主动开启相关设置。真实分析需要网络、有 Codex 使用权限的账号，并会使用账号额度。

## 验证范围

新增了登录流程与安全域名校验测试，并对安装、桌面/开始菜单快捷方式、卸载入口、安装版首次体验、内置组件连接和卸载清理进行验证。源码和安装包由同一版本构建，SHA256 校验值见附件。

本版本仍为预发布版本，暂不支持 Office/PDF/图片解析。安装包未做 Windows 代码签名，系统可能显示发布者未验证提示；请从本仓库下载并核对校验值。
