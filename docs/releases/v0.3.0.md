# 海克斯 Agent 0.3.0

现在可以在「连接与设置 → 模型与推理」选择模型、推理强度和响应速度。停止巡检、选择并保存，再重新开始即可生效；下次打开仍保留设置。问题分析和选牌处理都会使用这组参数。

模型及支持档位从当前连接读取，支持刷新列表和恢复默认。标准速度会覆盖继承的加速设置；加速可能增加额度消耗，实际速度和模型访问权限以账号及服务为准。

下载 `Hextech-Agent-Setup-0.3.0-x64.exe` 后按中文向导安装，使用桌面图标启动。安装包包含连接组件，无需命令行。Windows x64 预发布版本，安装包尚未签名。

验证包括 21 项行为测试、设置选择与保存的桌面检查，以及安装、快捷方式、内置连接和卸载流程。固定示例已使用 gpt-6.1-sol、低推理、标准速度完成真实三方案返回；这不是加速性能测试。
