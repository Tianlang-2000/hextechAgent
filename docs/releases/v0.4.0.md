# 海克斯 Agent 0.4.0

下载 `Hextech-Agent-Setup-0.4.0-x64.exe`，双击按中文向导安装，再打开桌面上的「海克斯 Agent」。可以先体验演示，或在「连接与设置」中登录 ChatGPT 并开始真实巡检。真实分析需要网络和具有 Codex 使用权限的账号。

本版增加巡检频率和每日调用次数上限、任务和报告恢复、文件节选去重以及问题依据行号。每日上限是本软件的调用次数，与账号额度不同；更深入分析或加速可能消耗更多额度。文件节选之外的内容不参与去重。

安装包支持 Windows x64，包含连接组件，无需安装 Node.js。预发布安装包尚未签名，Windows 可能提示发布者未知，请核对下载来源和 SHA256 校验文件。
