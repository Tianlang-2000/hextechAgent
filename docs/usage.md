# 使用指南

## 1. 启动与选择模式

下载 Setup 安装包，双击按中文向导完成安装。默认创建桌面和开始菜单图标，之后双击「海克斯 Agent」即可打开。首次欢迎页选择「先体验一下」，应用就会读取独立样例目录并展示三张方案牌，无需命令行或额外安装环境。

需要真实分析时，选择「连接我的 ChatGPT」并点击「登录 ChatGPT」，在浏览器中授权后回到软件。连接组件已包含在安装包中；已有可复用账号时自动显示就绪。真实分析仍需要账号拥有 Codex 使用权限。

| 模式 | 分析来源 | 是否需要登录 | 是否消耗额度 |
| --- | --- | --- | --- |
| 演示模式 | 固定演示判断与方案 | 否 | 否 |
| 真实分析 | 内置 Codex 组件调用模型返回的结果 | 是 | 是 |

演示模式用于验证交互。即使更换目录，它的判断仍是样例，不能用来确认文件中是否真的有问题。

## 模型、推理强度与速度

停止巡检后打开「连接与设置 → 模型与推理」。先检查连接或刷新列表，再选择模型、推理强度和响应速度，点击「保存设置」并重新开始巡检。选择会在重启后保留，问题发现和选牌处理使用同一组设置。演示模式可以保存，但只有真实分析会使用这些参数。

- 跟随连接配置：不覆盖本机已有设置。
- 推理强度：仅显示当前模型支持的档位；更深入的推理通常更耗时、消耗更多额度。
- 标准速度：显式覆盖已有加速配置；加速选项仅在目录提供时显示，可能增加额度消耗。

切换模型会重置不兼容档位，列表失效时会保留原选择并提示重新选择。刷新不调用推理模型。目录不保证账号拥有全部模型权限，实际响应速度也受服务状态影响。

## 2. 选择监听目录

在「连接与设置」中可选择未变化文件的复查频率，也可设置每日模型调用次数上限。该上限按本机自然日统计，分析和选牌处理各计一次，包含可能失败或中断的调用，与 Codex 账号额度不是同一指标；达到上限后需要调整设置或次日手动重启。

当前问题、待看发现和已生成报告会按目录和模式分别保存，重新开始巡检时恢复。执行过程中关闭应用时，未完成的操作不会自动重放。问题依据中的行号仅表示原文在当时读取的文件节选中匹配，不能保证判断正确，文件也可能已改变。

待检查队列和正在分析的文件也会保存，恢复时新动作仍优先。成功分析过的文件会按读取到的内容节选去重：内容节选没有变化时跳过模型调用；主动选择「继续深入」仍会分析。超过节选范围的变化不会被此去重识别。

在主界面点击「更换目录」。修改设置之前需要先停止巡检。

- 演示模式默认使用应用数据目录下的 `demo-workspace`。
- 切换到本机 Codex 时，默认目录为操作系统识别的桌面位置。
- 可以改为项目文件夹、工作资料目录或专门的测试目录。
- 监听包含子目录；文件写入稳定 800 毫秒后才进入分析队列。

左侧的文件夹入口会打开当前目录，便于添加文件、观察变化。

## 3. 三张方案牌

Codex 发现有依据的问题时，需要同时返回三个完整且不同的方案。海克斯校验通过后，才会在主界面和悬浮窗出牌。

每张牌包含方案名称、说明、预估工作量和风险。估算属于模型输出，不是执行时间承诺。

- **选择方案**：开始处理选定方案。
- **暂时跳过**：转向待看发现或继续巡检，不执行当前方案。
- **悬浮窗横线**：收起卡牌，后台监听继续运行。
- **窗口关闭按钮**：退出整个应用，同时停止任务。

当前卡牌不会被后台结果覆盖。新发现进入待看列表，新动作相关发现会排在前面。

## 4. 只读报告与可写处理

### 默认：只读生成报告

选牌后生成包含改法、步骤和验证建议的 Markdown 报告。源文件保持只读，界面不会把这一步表示为已经修复。

点击「查看执行报告」可阅读本轮内容，再点击「打开报告文件」可以使用本机默认应用打开原始文件。

### 可选：允许修改文件

先停止巡检，在设置中开启「选牌后允许修改文件」，再重新开始。之后用户选择方案时，Codex 会在可写沙箱中尝试执行，并返回实际处理和验证结果。

仅开启开关不会自动执行所有发现。需要用户逐次选牌；无法完成的步骤应在报告中说明。应用不自动批准需要额外权限的工具请求，每次重新启动都会关闭可写开关。

## 5. 两张后续牌

本轮报告生成后，会出现两个选择：

| 选择 | 后续行为 |
| --- | --- |
| 继续深入 | 将上一轮问题与报告作为上下文，重新检查对应文件及相关问题 |
| 继续巡检 | 优先展示待看发现；没有待看发现时继续轮转扫描 |

生成报告后，普通后台分析暂缓，等待用户选择。新文件、新建文件夹及内容更新仍会优先检查。

## 6. 新动作如何优先

文件新增、文件夹新增和内容修改都会进入优先队列。同一文件的连续更新会合并，减少重复排队。

有新动作时，正在进行的后台分析会被取消并重新排队，随后先处理新动作。当前用户已选定的方案处理不会被文件事件中途打断，相关事件会排队等待。

空文件夹也会根据名称和目录项判断是否涉及新任务。真实模式要求有证据再提出问题，不会仅凭文件夹名称就声称存在缺陷。

## 7. 停止与额度

- 点击「停止巡检」会关闭监听、取消分析、停止定时轮转并终止 Codex 子进程。
- 关闭窗口会执行停止流程并退出应用。
- 读取到 Codex 额度耗尽，或收到相关额度错误时，应用自动停止。
- 额度数据不可读取时显示「暂不可用」，不能据此判断账号额度为零。
- 恢复额度或修复连接后，需要手动重新开始。应用不自动购买额度，也不消耗额度重置权益。

## 8. 文件范围与数据位置

支持的扩展名包括：

```text
.ts .tsx .js .jsx .vue .json .md .txt .csv .yaml .yml
.html .css .scss .py .go .rs .java .sql .xml .toml
```

扫描器跳过符号链接、二进制内容、常见依赖和构建目录，以及 `.git`、`.codex`、`.agents`、`.aws`、`.ssh`、`.env*`、密钥扩展名和匹配敏感名称的文件。过滤规则见 `electron/policy.ts`。

设置、演示素材和报告分别保存在 Electron 应用数据目录中的：

```text
settings.json
demo-workspace/
reports/
```

Windows 通常位于 `%APPDATA%` 下的应用目录，具体位置取决于开发版或打包版的应用名称。报告不会写回被监听的源文件目录。界面活动记录和待看发现保存在当前进程内，退出后不恢复。

真实模式会向 Codex 提供文件节选、相对路径、问题和必要上下文。扫描器过滤决定海克斯主动读取哪些内容，Codex 工具的可读范围仍取决于本机配置和沙箱；本项目不提供独立的文件级隔离容器。
